The unsupported features were `--page-fallback` / `SERVER_FALLBACK_PAGE`. The worker files are kept verbatim as raw evidence.
- Every HTTP result was served with a local native static-web-server 2.38.0 (the version Anybuild's plan pins; Wasmer's hosted runtime uses its own WASI static-web-server package, which was not tested here). The only deviation is `--host=127.0.0.1`.

- For CoreUI and Sneat, the duplicate-PR fallback used GitHub search through a tool on repositories outside this session's configured repo scope. The searches were read-only, and their output is kept under `duplicate-search/`.
