A small FastAPI + [Pillow](https://python-pillow.org/) app that downloads an image, rotates and crops it, and returns a PNG.
Source snapshot: [`wasmerio/examples` → `python-pillow`](https://github.com/wasmerio/examples/tree/dd8532fcc1aebf8554f5b904332c3778f5246ffb/python-pillow) at `dd8532fc`, plus a `DEFAULT_IMAGE_URL` setting.

## Configuration

| Variable | Required | Effect |
| --- | --- | --- |
| `DEFAULT_IMAGE_URL` | Yes (button) | Image URL prefilled in the form. Falls back to `https://picsum.photos/200/300` locally. |

## Run locally

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Open `http://127.0.0.1:8000/`, submit the form, and `/process` returns the rotated, cropped PNG.

`/process` fetches any URL you give it. Keep this as a demo; do not expose it as a general image proxy.
