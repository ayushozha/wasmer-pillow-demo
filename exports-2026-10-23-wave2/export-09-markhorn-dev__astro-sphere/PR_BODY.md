## Summary

Adds a Deploy to Wasmer badge to the README, on its own line below the existing Vercel and Netlify buttons in "Deploy your own". This is a two-line README change with no code or config changes.

Disclosure: I work at Wasmer. I prepared this change with help from Claude, an AI assistant, and reviewed and tested it before opening this PR.

The button opens Wasmer's import page for this public repository, where you review the detected build settings and click Deploy; it does not create a copy of the repository in your GitHub account. To customize the site and redeploy on changes, fork the repository and import your fork instead.

## Why this repo

Astro Sphere is a static portfolio and blog theme, and its README already offers one-click deploys. Wasmer's builder detects it as a static Astro site, runs the same `npm install` and `npm run build` the README documents, and serves `dist/`, so the theme deploys as-is.

## Testing

All on `f7e3a40f20e1267d7fbbb7b6dd868df1845e1d82` (current `main`) with this change applied, as a local replay of the plan generated by Wasmer's builder (Anybuild v0.33.0):

- Detected: static Node.js provider, framework Astro, npm 11, output directory `dist`.
- `npm install` (Node 24.22.1, npm 11.21.1, with only `package.json` and `package-lock.json` staged first, as the builder does): exit 0.
- `npm run build` (`astro check && astro build`): exit 0, 0 errors; 45 files in the output.
- `dist/` served with a local native static-web-server 2.38.0 (the version Anybuild's plan pins; Wasmer's hosted runtime uses its own WASI static-web-server package, which was not tested here).
- `curl` results: `/`, `/blog/`, `/blog/01-astro-sphere-file-structure/`, `/projects/`, `/projects/project-1/`, `/search/`, `/work/`, `/legal/privacy/`, `/rss.xml`, `/sitemap-index.xml`, `/sitemap-0.xml` and `/robots.txt` returned 200; `/no-such-page-xyz/` and `/missing.html` returned 404.
- All 40 same-origin URLs referenced from the 17 built HTML pages resolve: 24 returned 200 directly, and the 16 internal links written without a trailing slash (for example `/blog`) returned a 308 redirect to the slash form, which then returned 200.

## Limitations

- No deployment was made. The Wasmer import page and the badge image were not opened from the test environment.
- `astro.config.mjs` sets `site` to the Vercel demo URL, so canonical, Open Graph, RSS and sitemap URLs point there until a deployer changes it, as on any host.
- The built pages load no third-party scripts or analytics; links to GitHub, Twitter and LinkedIn are plain outbound links. There is no custom 404 page, so missing paths get the server's default 404.
- The repository has had little recent maintainer activity (last commit on `main`: 2025-06-16), so I understand if this is not reviewed soon.
